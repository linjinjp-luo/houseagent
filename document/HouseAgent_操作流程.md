# HouseAgent 1.0 操作流程

> 界面默认是日文，可在左下角切换为「简体中文」。本文按中文界面的名称说明。

## 一、启动与停止

1. 在项目目录打开 PowerShell，执行 `.\scripts\start.ps1`，浏览器会自动打开 `http://127.0.0.1:8765`。
2. 停止时执行 `.\scripts\stop.ps1`。
3. 所有数据只保存在本机（`%LOCALAPPDATA%\HouseAgent\`），升级前会自动备份数据库。

## 二、基本使用流程

### 1. 准备网站（「网站与账号」）

- **能自动搜索的网站（如 SUUMO）**：展开「网站规约与 robots.txt 自动检查」，阅读检查结果后点击「同意并启用」（仅限个人用途）。
- **需要登录的网站**：点击「添加网站账户」，然后「打开登录窗口」，在弹出的窗口里自己登录，再点击「检查登录状态」。账户是可选的，公开搜索不需要账户。
- **有人机验证的网站（如 at home、HOME'S）**：把卡片上的「浏览器辅助导入」设为「开启」（默认的「自动」模式会在检测到验证后自动开启）。
- **列表里没有的网站**：点击「+ 添加网站」，填写网站名称和搜索入口 URL 即可，不需要开发。

### 2. 新建搜索任务（「搜索任务」→「新建任务」）

按向导填写 5 步：基本信息 → 搜索条件（购买/租赁、地区、价格、面积、户型等）→ 网站与账户 → 执行计划（手动、每天、每周、间隔、启动时）→ 确认保存。

### 3. 执行搜索

- **自动搜索**：在任务行点击「立即搜索」，可以看到进度百分比；完成或失败都会提示结果和原因。
- **浏览器辅助导入**（有人机验证的网站）：点击「浏览器辅助导入」，在弹出的浏览器里自己完成验证、打开结果列表，再回到 HouseAgent 点击「导入当前页面」。翻页后再导入一次即可。
- **手动登记**：在「房源管理」点击「手动登记」，录入自己看到的房源。

### 4. 查看与管理房源

- **「房源管理」**：筛选、排序、打标签、收藏（★）；每条房源都保留原网站链接。
- **房源详情**：价格变化曲线、各网站刊登记录、笔记。
- **「收藏与调查」**：记录看房状态和调查进度。
- **「统计分析」「任务日志」**：查看趋势和每次运行的详细记录。

## 三、AI 使用方法（可选）

AI 默认关闭。不开 AI 时，搜索、房源管理、投资评估的规则计算和手工标签都能正常使用。

### 1. 配置 AI 服务（「系统设置」→「AI」）

1. 勾选「启用 AI（履历摘要与投资评估）」，点击右上角「保存」。
2. 点击「+ 添加 AI 服务」：
   - 服务商：选择 Anthropic、OpenAI 或兼容接口（企业网关、本地模型）。
   - 模型：会预填推荐模型，也可以自己填写模型 ID。
   - API Key：填写你自己的 Key。Key 只保存在 Windows 的安全存储里，界面只显示末尾 4 位。
   - 调用限额：每日次数、费用上限、每批数量等，可以按需调整。
3. 保存后点击「测试连接」，显示「通过」即可使用。
4. 配置了多个服务时，点击「设为使用中」来切换。

### 2. 建立投资评估标准（「系统设置」→「投资评估标准」）

点击「新增标准」，填写：

- 目标类型：全部比较、翻新转售、出租收益或自住。
- 目标：最低毛回报率/净回报率、最低转售利润和利润率、要求的折价幅度等。
- 费用假设：购入费用率、出售费用率、空置率、年招租成本。
- 自住偏好：区域、面积、户型、通勤时间。

**没填的项目不会按 0 计算，依赖它的判断会显示为「数据不足」。**

### 3. 评估一套房源（房源详情 →「投资价值辅助评估」）

1. 点击「录入调查数据」，填写网站上没有的信息，并注明来源：预估租金、管理费、修缮基金、税费、保险、翻新预算、预计售价、装修状况、已知风险等。
2. 选择评估标准，勾选「使用 AI 解释」，点击「执行评估」。
3. 查看评估结果：
   - **主结论**：翻新转售候选、高收益出租候选、优质自住候选、投资价值偏低、数据不足待确认。
   - **其他内容**：事实标签、参考分、置信度、主要理由、风险提示、缺失数据和下一步调查建议。
   - **「计算公式与数值」**：每个金额和回报率的计算方法。
   - **「数据来源与版本」**：每个数字的来源，以及使用的规则和模型版本。
4. 不认同结论时，点击「修正判定」并填写理由。AI 原来的结论会保留，列表里显示你的判定。
5. 数据或价格变化后会提示可以重新评估；每次评估都会新增一条记录，可以在历史里对比。

### 4. 批量评估

- **「房源管理」**：勾选房源后点击「投资评估所选 N 套」。
- **「收藏与调查」**：点击「评估收藏房源」。
- 开始前会显示套数、需要调用 AI 的次数和预计费用，确认后才开始。达到每日上限会自动暂停，不会继续产生费用。
- **「新建任务」→「基本信息」**：勾选「搜索完成后执行评估」，每次搜索后会自动评估新增和变化的房源（默认关闭）。

### 5. 其他

- **AI 摘要**：房源详情里的「AI 摘要」按钮会用通俗的话总结价格和状态的变化。
- **用量查看**：在「系统设置」→「AI」→「用量」里查看调用次数和估算费用，以服务商账单为准。
- **提示**：AI 评估只用于初步筛选，不是专业估价、建筑检查、法律调查或投资建议。金额都是按你录入的数据用公式计算的，AI 不会编造租金、成本、售价或税费。
